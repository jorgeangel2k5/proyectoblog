# 🍴 Recetas Locas - Proyecto Blog Gastronómico

¡Bienvenidos a **Recetas Locas**! Este es un proyecto de blog de recetas locas. El sitio web ofrece una interfaz amigable, adaptándose dinámicamente a distintos dispositivos.

## 📋 Estructura y Características de las Páginas

### 🏠 1. Página de Inicio (`index.html`)
* **Navegación Fija:** Menú oscuro  con diseño consistente en todo el sitio.
* **Suscripción Interactiva:** Ventana modal de Bootstrap con formulario integrado para captación de usuarios.
* **Grilla de Contenidos:** Tarjetas de recetas organizadas mediante el sistema de grillas responsivo de Bootstrap.
* **Footer:** Pie de página unificado con enlaces externos a redes sociales (Facebook, Instagram, YouTube).

### 🍕 2. Entrada de Blog (`pages/entrada.html`)
* **Contenido Multimedia:** Imagen principal de la receta y video tutorial incrustado directamente desde YouTube.
* **Sección de Comentarios:** Visualización fluida de 5 comentarios reales ficticios con formato limpio de tarjetas Bootstrap.
* **Formulario de Opinión:** Formulario interactivo con validación para que los usuarios puedan dejar sus consultas (Nombre, Email y Mensaje).
* **Barra Lateral (Sidebar):** Buscador integrado, categorías del blog y carrusel de imágenes adaptativo.

### 📞 3. Página de Contacto (`pages/contacto.html`)
* **Sistema de Grillas:** Distribución en 2 columnas en pantallas de PC (50% formulario, 50% mapa) y 1 columna vertical en dispositivos móviles.
* **Formulario Completo:** Campos requeridos de interacción (Nombre, Email, Asunto y Mensaje) con botones estilizados.
* **Mapa Interactivo:** Inserción de un mapa a través de un `<iframe>` de Google Maps para la localización física del emprendimiento.

### 🔐 4. Página de Login (`pages/login.html`)
* Formulario de inicio de sesión centrado y responsive.
* Validación visual de campos para el ingreso de usuario (Email) y contraseña.

### 👥 5. Página de Nosotros (`pages/nosotros.html`)
* Sección de presentación de los desarrolladores y la misión del blog.

### 🛠️ 6. Página de Error (`pages/404.html`)
* Página de redirección personalizada para búsquedas inexistentes o enlaces caídos del blog.
